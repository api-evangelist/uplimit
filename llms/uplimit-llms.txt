# Uplimit

> Uplimit is an AI-native corporate learning platform (formerly CoRise) that generates personalized, adaptive training programs with AI instructors, practice simulations, real-time feedback, and mastery measurement. Its Organization API lets enterprise customers manage users, course and session enrollments, SSO identity bindings, and learner-activity exports.

Generated by API Evangelist on 2026-07-21 from the provider's published surfaces (uplimit.com did not publish its own /llms.txt at generation time).

## APIs

- [Uplimit Organization API](https://github.com/uplimit/api-clients): Manage organizations within the Uplimit platform — users, enrollments, courses, sessions, SSO authentication methods, and learner-activity exports. Base URL: https://uplimit.com/api/organization/ (HTTP Bearer auth, version 2025-08-18).
